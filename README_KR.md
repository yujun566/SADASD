# Discord RPG Bot (수정판 / 단일 파일 통합)

이번 요청에 따라 모든 코드를 **`main.py` 하나로 통합**했고, "가끔 상호작용 실패(이 상호작용을
처리하지 못했습니다)" 오류의 원인이 되던 버그들을 수정했습니다.

## 무엇이 문제였고 어떻게 고쳤는지

1) **타일 렌더링이 화면 셀 하나마다 DB 커넥션을 새로 열었음**
   - 기존 `render_world()`는 화면에 보이는 칸(zoom 단계에 따라 최대 17x17=289칸) 하나하나마다
     `tile_at()` → 개별 SQLite 커넥션 열기/쿼리/닫기를 반복했습니다.
   - 여러 유저가 동시에 이동하거나 5초마다 도는 자동 새로고침 루프가 겹치면 이 지연이 누적되어
     디스코드의 **3초 응답 제한**을 가끔 넘겨버렸고, 그게 "상호작용 실패"로 나타났습니다.
   - **수정**: 화면 범위의 설치물/채집지 정보를 **쿼리 1번**으로 모두 가져온 뒤, 순수 계산 함수로
     각 타일을 결정하도록 바꿨습니다. (테스트 결과: zoom 3단계 렌더링 기준 기존 대비 매우 빨라짐)

2) **쿼리 1번마다 새 SQLite 커넥션을 열고 닫음 + 잠금 처리 없음**
   - 버튼 하나 누를 때마다 내부적으로 수십 번의 DB 왕복이 발생했고, 각 왕복마다 완전히 새로운
     커넥션을 만들었습니다. 동시 접속자가 늘면 `database is locked` 오류가 간헐적으로 발생했고,
     이 예외가 별도로 처리되지 않아 상호작용이 응답 없이 끝나버렸습니다.
   - **수정**: 프로세스 전체에서 커넥션을 하나만 유지하고 `asyncio.Lock`으로 순서를 보장하도록
     재작성했습니다. WAL 모드 + `busy_timeout`도 함께 설정했습니다. (50명 동시 이동/렌더링
     시뮬레이션에서 잠금 오류 없이 1초 이내 처리됨을 확인했습니다.)

3) **버튼/모달 콜백이 무거운 DB 작업을 먼저 하고 나서야 첫 응답을 보냄**
   - 이동/전투/장착/제작/인챈트 등 모든 버튼 콜백이 DB 작업을 마친 뒤에야
     `interaction.response.edit_message()`를 호출했습니다. 처리 시간이 조금만 길어져도
     3초 내 응답이 늦어져 실패로 보였습니다.
   - **수정**: 모든 버튼/모달 콜백에서 **가장 먼저** `interaction.response.defer()`로 즉시
     응답(ack)을 보낸 뒤, 실제 작업은 그 다음에 처리하고 결과를 메시지 수정으로 반영하도록
     순서를 바꿨습니다.

4) **`WormView` 클래스가 실제로는 정의되어 있지 않았음**
   - `worm_cog.py`가 `from utils.buttons import WormView`를 했지만 `buttons.py`에는 해당
     클래스가 없어 **임포트 단계에서부터 실패**했고, `/worm` 지렁이 게임 기능 전체가
     항상 로드되지 않고 있었습니다.
   - **수정**: 이동(⬆⬅⬇➡) 및 재시작 버튼을 가진 `WormView`를 정상적으로 구현했습니다.

5) **예외 발생 시 상호작용이 무응답으로 남는 문제**
   - 처리 중 어떤 예외든 발생하면(버그, 일시적 DB 문제 등) 아무 응답도 가지 않아 사용자에게는
     항상 "상호작용 실패"로만 보였습니다.
   - **수정**: 모든 View / 슬래시 커맨드에 에러 핸들러를 추가해, 예외가 나도 항상 사용자에게
     "⚠️ 처리 중 오류가 발생했습니다" 같은 안내 메시지가 가도록 하고, 서버 로그에는 상세한
     스택트레이스를 남기도록 했습니다.

## 실행 방법
1. Python 3.11 이상 설치
2. 압축 해제 후 `rpg_bot` 폴더로 이동
3. 의존성 설치: `pip install -r requirements.txt`
4. `.env.example`을 `.env`로 복사한 뒤 토큰/개발자 ID 입력
5. 실행: `python main.py`

## 구조
이제 모든 로직(설정, DB, 아이템/인벤토리, 플레이어, 월드, 전투, 렌더링, 지렁이 게임,
UI 컴포넌트, 코그, 봇 실행부)이 **`main.py` 한 파일**에 순서대로 정리되어 있습니다.
각 섹션은 파일 내 주석으로 구분되어 있고, 이번에 수정한 부분에는 `[FIX]` / `[수정사항]`
표시를 남겨두었습니다.

## 슬래시 커맨드
- `/rpg` : 공개 RPG 패널 생성
- `/worm` : 지렁이 게임
- `/market`, `/buy`, `/wallet` : 거래/재화
- `/chatlog`, `/guild_create`, `/guild_join`, `/whohere` : 소셜
- `/craft_list` : 제작 목록 확인
- `/dev_tp`, `/dev_item`, `/dev_items_list`, `/dev_id` : 개발자 전용 (DEV_IDS에 등록된 유저만 사용 가능)
